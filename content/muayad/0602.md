**هي نفسها قوانين القاعدة المشتركة فقط استبدال كل $I_E$ إلى $I_B$:**

$$I_C = I_E - I_B$$

| الأرباح | أوم | قدرات |
| --- | --- | --- |
| $Av = \dfrac{V_{out}}{V_{in}}$ | $V_{in} = I_B * R_{in}$ | $V_{in} = I_B * R_{in}$ |
| $\alpha = \dfrac{I_c}{I_B}$ | $V_{out} = I_C * R_{out}$ | $V_{out} = I_C * R_{out}$ |
| $G = \alpha \cdot Av$ | | |
| $G = \dfrac{P_{out}}{P_{in}}$ | | |

- تيار قاعدة ⟵ $I_B$
- تيار باعث ⟵ $I_E$
- تيار جامع ⟵ $I_C$

**كل من: α , Av , G هو عدد مجرد من الوحدات أي بدون وحدات**
