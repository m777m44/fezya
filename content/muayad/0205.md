## ملاحظة

إذا كان متجه $\vec{B}$ // مستوى الحلقة أو إذا كان متجه $\vec{B} \perp A$ فإن الزاوية $90^{\circ}$ فإن $\cos 90^{\circ} = 0$ ينعدم الفيض المغناطيسي $\Delta \phi_B = 0$.

- إذا أعطى في سؤال مقاومتين نجمعهم.
- \* تناقص الفيض يبقى قيمة سالبة.

| التحويل / النسبة | القيمة |
| --- | --- |
| cm ⇒ | $\times 10^{-2}\,\mathrm{m}$ |
| cm² ⇒ | $\times 10^{-4}\,\mathrm{m^{2}}$ |
| 1) $\dfrac{T}{s}$ | $= \dfrac{\Delta B}{\Delta t}$ |
| 2) $\dfrac{w.b}{s}$ | $= \dfrac{\Delta \phi_B}{\Delta t}$ |
| 3) $\dfrac{m^{2}}{s}$ | $= \dfrac{\Delta A}{\Delta t}$ |

تتلاشى أي مقدار من وإلى نأخذ قيمتين: $\Delta B = B_2 - B_1$
