| فولطية آنية | فولطية محتثة عظمى |
| --- | --- |
| $\varepsilon_{ins} = \varepsilon_{max}\, \omega t$ | $\varepsilon_{max} = N A \omega B$ — نواپ |
| إذا طلب أو أعطى قوة دافعة كهربائية محتثة آنية | إذا طلب أو أعطى فولطية عظمى |
| $I_{ins} = \dfrac{\varepsilon_{ins}}{R}$ | $I_{max} = \dfrac{\varepsilon_{max}}{R}$ |
| إذا طلب أو أعطى تيار آني | إذا طلب أو أعطى تيار أعظم |
| $P_{ins} = I_{ins}\, \varepsilon_{ins}$ — $P_{ins} = I_{ins}^{2} \times R$ | $P_{max} = I_{max}\, \varepsilon_{max}$ — $P_{max} = I_{max}^{2} \times R$ |
| إذا طلب أو أعطى قدرة آنية | إذا طلب أو أعطى قدرة عظمى |

> ملاحظة المحرر: وردت صيغة الفولطية الآنية في الأصل بالشكل $\varepsilon_{ins} = \varepsilon_{max}\, \omega t$ كما هي أعلاه.
