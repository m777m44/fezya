## قوانين المجموعة الأولى: شحنة - نصف قطر - حجم - كثافة

| وحدة | اسمه | الرمز |
| --- | --- | --- |
| كولوم C | شحنة النواة | q |
| كولوم C | شحنة الالكترون | e |
| ---------- | العدد الذري | Z |
| فيرمي F متر | نصف قطر النواة | R |
| ---------- | ثابت التناسب | r₀ |
| ---------- | العدد الكتلي | A |
| m³ | حجم النواة | V |

- **شحنة النواة:** $q = Ze$
- **نصف قطر النواة:** $R = r_\circ \sqrt[3]{A}$ ، $V = \dfrac{4}{3}\pi R^{3}$
- **حجم النواة:** $V = \dfrac{4}{3}\pi R^{3}$
- **الكثافة:** $\rho = \dfrac{m}{V}$

**مخطط (سحابة):** $A = Z + N$ — العدد الكتلي = العدد الذري + العدد النيوتروني

## قوانين المجموعة الثانية: طاقة الربط - معدل طاقة الربط - النقص الكتلي

| وحدة | اسمه | الرمز |
| --- | --- | --- |
| u | النقص الكتلي | Δm |
| Mev | طاقة الربط | E_b |
| ---------- | معدل طاقة الربط | E_b′ |
| u | كتلة الهيدروجين | M_H |
| u | كتلة النيوترون | M_n |
| ---------- | كتلة الذرة المطلوبة | M |

- **النقص الكتلي:** $\Delta m = Z M_H + N M_n - M$
- **طاقة الربط النووي:** $E_b = \Delta m c^{2}$
- **طاقة الربط النووي:** $E_b = [Z M_H + N M_n - M] c^{2}$
- **معدل طاقة الربط النووي:** $E_b' = \dfrac{E_b}{A}$
