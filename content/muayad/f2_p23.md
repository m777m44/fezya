## فصل سادس مجموعة أولى

$$KE_{max} = E - w$$

**حسام = حسين − كمال**

| الطاقة الحركية | طاقة الفوتون | دالة الشغل |
| --- | --- | --- |
| $KE_{max} = \dfrac{1}{2} m V_{max}^{2}$ | $E = hf$ | $w = hf_\circ$ |
| $KE = eV_s$ | $E = \dfrac{hc}{\lambda}$ | $w = \dfrac{hc}{\lambda_\circ}$ |

## الرموز (الأول)

| الرمز | الدلالة |
| --- | --- |
| C | سرعة الضوء $3 \times 10^{8}\ m/s$ |
| λ | طول موجي m |
| f₀ | تردد العتبة Hz |
| λ₀ | طول موجة العتبة m |

## الرموز (الثاني)

| الرمز | الدلالة |
| --- | --- |
| KE_max | طاقة حركية عظمى للالكترونات J |
| E | طاقة فوتون J |
| w | دالة الشغل J |
| m_e | كتلة الالكترون $9.11 \times 10^{-13}\ Kg$ |
| V_max | الانطلاق الاعظم للالكترونات m/s |
| e | شحنة الالكترون $1.6 \times 10^{-19}\ C$ |
| V_s | جهد الايقاف او القطع V |
| h | ثابت بلنك $6.63 \times 10^{-34}\ J.s$ |
| f | التردد Hz |

> ملاحظة المحرر: كتلة الالكترون في الأصل مكتوبة $9.11 \times 10^{-13}\ Kg$، والصحيح $9.11 \times 10^{-31}\ Kg$.
