## فصل ثالث مجموعة ثانية

### ملخص قوانين المحث الصرف والمتسعة الصرف

**المحث الصرف**

1. $$X_L = 2\pi f L$$
2. $$X_L = \omega L$$
3. $$X_L = \dfrac{V_L}{I_L}$$
4. $$I_L = \dfrac{V_L}{X_L} \qquad , \qquad V_L = X_L . I_L$$

**السعة الصرف**

5. $$X_C = \dfrac{1}{2\pi f C}$$
6. $$X_C = \dfrac{1}{\omega C}$$
7. $$X_C = \dfrac{V_C}{I_C}$$
8. $$I_C = \dfrac{V_C}{X_C} \qquad , \qquad V_C = X_C . I_C$$

## الرموز

| الرمز | الدلالة |
| --- | --- |
| X_L | رادة الحث Ω |
| f | تردد الدائرة Hz |
| L | معامل الحث الذاتي H |
| ω | تردد زاوي rad/s |
| V_L | فولطية محث V |
| I_L | تيار محث A |
| X_C | رادة السعة Ω |
| C | سعة المتسعة F |
| V_C | فولطية السعة V |
| I_C | تيار السعة A |
