# جوهرة الفيزياء — الأستاذ علي السوداني

## فصل أول مجموعة أولى

$$C = \dfrac{\varepsilon_\circ A}{d} \qquad\qquad\qquad C = \dfrac{Q}{\Delta V}$$

| الرمز | الدلالة |
| --- | --- |
| C | سعة متسعة F |
| A | مساحة $m^{2}$ |
| d | البعد m |
| ε₀ | سماحية الفراغ $8.85 \times 10^{-12}$ |

| الرمز | الدلالة |
| --- | --- |
| C | سعة متسعة F |
| Q | الشحنة C |
| ΔV | فرق الجهد V |

**انتبه:** يستخدم هذا القانون في حالة وجود مساحة وبعد.

**انتبه:** يستخدم هذا القانون في حالة وجود الشحنة وفرق الجهد.
