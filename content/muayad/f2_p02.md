## ملاحظة

**شلون تعرف السؤال تابع الى الجوهرة الاولى اذا ذكر كلمة متسعة فقط**

### ١) السعة قبل ادخال العازل (ماكو عازل)

$$C = \dfrac{Q}{\Delta V}\ \text{سكف} \qquad \text{[شحنة + فرق جهد] سعة}$$

$$\text{سين} \quad Q = C.\Delta V \qquad \text{شحنة}$$

$$\text{فقس} \quad \Delta V = \dfrac{Q}{C} \qquad \text{فرق جهد}$$

$$\text{افديك} \quad E = \dfrac{\Delta V}{d} \qquad \text{مجال كهربائي}$$

$$\text{ايدا} \quad C = \dfrac{\varepsilon_\circ A}{d}$$

**الرموز:**

| الرمز | الدلالة |
| --- | --- |
| C | سعة متسعة F |
| Q | الشحنة C |
| ΔV | فرق الجهد V |
| E | مجال كهربائي V/m |
| d | البعد m |
| ε₀ | سماحية الفراغ $8.85 \times 10^{-12}$ |
| A | المساحة $m^{2}$ |

**المساحات:**

| دائرة | مستطيل | مربع |
| --- | --- | --- |
| $A = \pi r^{2}$ | $A = x.y$ | $A = [L]^{2}$ |
| نصف القطر ² في النسبة الثابتة | الطول في العرض | طول الضلع ² |

### ٢) السعة بعد ادخال العازل (اكو عازل)

**الرموز:**

| الرمز | الدلالة |
| --- | --- |
| C_K | سعة متسعة بوجود عازل F |
| ΔV_K | فرق الجهد بوجود عازل V |
| Q_K | الشحنة بوجود عازل C |
| E_K | مجال كهربائي بوجود عازل V/m |
| K | ثابت العزل |
| C | سعة متسعة F |
| ΔV | فرق الجهد V |
| Q | الشحنة C |
| E | مجال كهربائي V/m |

$$C_K = K.C \qquad \text{يستخدم اذا كانت المتسعة متصلة أو منفصلة}$$

$$\Delta V_K = \dfrac{\Delta V}{K} \qquad \text{يستخدم إذا كانت المتسعة منفصلة فقط}$$

$$E_K = \dfrac{E}{K} \qquad \text{يستخدم إذا كانت المتسعة منفصلة فقط}$$

$$Q_K = K.Q \qquad \text{يستخدم إذا كانت المتسعة متصلة فقط}$$

**⚠ أثبت:**

$$Q = Q_K\ \text{منفصلة} \qquad E = E_K\ \text{متصلة} \qquad \Delta V = \Delta V_K\ \text{متصلة}$$
