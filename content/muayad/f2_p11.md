## فصل ثاني مجموعة ثانية

### الجوهرة الثانية المسائل حلقة، ملف:

$$\Phi_B = A B \cos\theta$$

## انتبه على الزاوية

- اذا ذكر في السؤال كلمة **مستوية، متوازية، متعاملة**: $\cos 0 = 1$
- اذا ذكر الزاوية تقع بين $\vec{B}, \vec{A}$ تؤخذ كما هي.
- اذا ذكر تصنع زاوية مع المستوي: **زاوية السؤال** $\theta = 90 - \ldots$

$$\text{حلقة} \quad \varepsilon_{ind} = -\dfrac{\Delta \Phi_B}{\Delta t} = -\dfrac{A B \cos\theta}{\Delta t}$$

$$\text{ملف} \quad \varepsilon_{ind} = -N \dfrac{\Delta \Phi_B}{\Delta t} = -N \dfrac{A B \cos\theta}{\Delta t}$$

$$\text{التيار المحث} \quad I_{ind} = \dfrac{\varepsilon_{ind}}{R}$$

## الرموز

| الرمز | الدلالة |
| --- | --- |
| ε_ind | ق.د.ك.م (V) |
| I_ind | تيار محث (A) |
| Φ_B | فيض مغناطيسي (web) |
| A | مساحة $m^{2}$ |
| B | كثافة فيض T |
| Δt | تغير بالزمن (s) |
| N | عدد لفات الملف |
| R | مقاومة Ω |
| r | نصف قطر m |
| D | قطر m |
| π | نسبة ثابتة 3.14 |

**⚠ انتبه:**

- لاستخراج المساحة نستخدم: $A = \pi r^{2}$
- لاستخراج نصف القطر: $r = \dfrac{D}{2}$
- اذا ذكر في السؤال مساحتين: $\Delta A = A_2 - A_1$
- اذا ذكر في السؤال كثافتين: $\Delta B = B_2 - B_1$

**⚠ انتبه:**
