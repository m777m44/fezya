# فكرة وزارية ربط الطاقة بالتوازي

**ملاحظة / إذا أعطى طاقة أكتب قانون الطاقة**

**الطاقة الأولى**

$$P.E_1 = \dfrac{1}{2} C_1 . \Delta V_1^{2} \quad \text{نستخرج } (\Delta V_1)$$

| توازي | توالي |
| --- | --- |
| $\Delta V_1 = \Delta V_T = \Delta V_2$ | $Q_1 = C_1 \Delta V_1$ ثم ثبت Q |
| | $Q_1 = Q_T = Q_2$ |

**الطاقة الثانية**

$$P.E_2 = \dfrac{1}{2} C_2 . \Delta V_2^{2} \quad \text{نستخرج } (\Delta V_2)$$

| توازي | توالي |
| --- | --- |
| $\Delta V_1 = \Delta V_2 = \Delta V_T$ | $Q_2 = C_2 \Delta V_2$ ثم ثبت Q |
| | $Q_2 = Q_1 = Q_T$ |

**ملاحظة**

- توازي دائماً أبحث عن $(\Delta V)$
- توالي دائماً أبحث عن $(Q)$

$$\Delta V_T = \Delta V_1 = \Delta V_2 \qquad\qquad Q_T = Q_1 = Q_2$$
