**المجموعة الدولية:-** دارة التيار المتناب الحمل فيها مقاومة صرف لمصدر الفولطية المتنابية الحمل مقاومة صرف (منطوق السؤال).

## القوانين - فصل الثالث

| المعادلات | المؤثرات | القدرات | الترددات |
| --- | --- | --- | --- |
| $V_R = V_m \sin(\omega t)$ — معادلة الفولطية | $V_{eff} = \dfrac{V_m}{\sqrt{2}}$ — مؤثر الفولطية | $P_{av} = V_{eff} I_{eff}$ — $P_{av} = \dfrac{1}{2} P_m$ — القدرة المتوسطة | الزاوي rad/s: $\omega = 2\pi F$ |
| $I_R = I_m \sin(\omega t)$ — معادلة تيار | $I_{eff} = \dfrac{I_m}{\sqrt{2}}$ — مؤثر التيار | $P_m = V_m I_m$ — $P_m = I_m^{2} R$ — القدرة العظمى | تردد الدائرة - المصدر: $F = \dfrac{\omega}{2\pi}$ |
| زاوية $\phi = 0$ | أو $R = \dfrac{V_{eff}}{I_{eff}}$ | $P_{dis} = I_{eff}^{2} R$ — القدرة المستهلكة | الوحدة Hz |
| عامل القسمة: $P.F = \cos 0 = 1$ | | | |

**أو:**

$$R = \dfrac{V_{eff}}{I_{eff}} \qquad , \qquad R = \dfrac{V_m}{I_m}$$

**شرط توافق أم الفولطية والرموز**

- إذا توفر m الأول الـ m الثاني أوم
- إذا توفر eff الأول الـ eff الثاني أوم

## خطوات الحل مقاومة صرف

1. اكتب المعادلة الموضوعة في السؤال
2. اكتب معادلة على الوزن
3. بالمقارنة اسرق من السؤال $[V_m, \omega]$
4. انتبه لمطاليب السؤال
