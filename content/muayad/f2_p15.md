## فصل ثالث مجموعة أولى

### ملخص المقاومة الصرف:

| التسلسل | العلاقة |
| --- | --- |
| 01 | $I_R = I_m \sin \omega t$ |
| 02 | $V_R = V_m \sin \omega t$ |
| 03 | $I_{eff} = \dfrac{I_m}{\sqrt{2}}$ |
| 04 | $I_{eff} = 0.707 I_m$ |
| 05 | $V_{eff} = \dfrac{V_m}{\sqrt{2}}$ |
| 06 | $V_{eff} = 0.707 V_m$ |
| 07 | $P_{avg} = I_{eff} . V_{eff}$ |

## الرموز

| الرمز | الدلالة |
| --- | --- |
| I_R | تيار المقاومة A |
| I_m | تيار الاعظم A |
| I_eff | تيار مؤثر A |
| V_eff | فولطية مؤثرة V |
| V_m | فولطية عظمى V |
| V_R | فولطية مقاومة V |
| ωt | زاوية طور rad |
| ω | تردد زاوي rad/s — $\omega = 2\pi f$ |
| f | تردد دائرة Hz |

## ملاحظات

**01** هو ينطي علاقة واني حافظ علاقة احذف المشابهات واطلع المعطيات.

**02** اذا طلب $[I_{eff}, V_{eff}]$ الاول يستخرج من القانون الاصلي والثاني من قانون اوم:
$$V_{eff} = I_{eff} . R \qquad I_{eff} = \dfrac{V_{eff}}{R}$$

**03** اذا طلب علاقة التيار نستخرج $I_m$ أولاً من خلال $I_m = \dfrac{V_m}{R}$ ثم نكتب العلاقة ونعوض المعطيات.
