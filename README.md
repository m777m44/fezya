# بوابة قوانين الفيزياء — السادس العلمي

موقع تعليمي عربي (RTL) يجمع قوانين وملاحظات الفيزياء للصف السادس العلمي، مبنيّاً كصفحات HTML ثابتة.

## الصفحات

| المسار | الوصف |
| --- | --- |
| `index.html` | الصفحة الرئيسية: فهرس الفصول الثمانية، أدوات حسابية تفاعلية، نصائح دراسية. |
| `notes.html` | **الموسوعة النصية الكاملة**: تفريغ نصي كامل للوحتين الممسوحتين ضوئياً (81 لوحة)، مرتّبة بحسب الملف والفصل، مع الصيغ الرياضية والجداول والملاحظات كما وردت في الأصل. |

## المصدر والمحتوى

- `content/muayad/*.md` — لوحة واحدة لكل ملف: frontmatter (`title`, `chapter`, `subject`, `page`) ثم متن Markdown مع LaTeX.
  - نطاق `01xx`–`08xx`: الملف الأول (قوانين الفيزياء — الأستاذ مؤيد سليم)، 54 لوحة.
  - نطاق `f2_pNN`: الملف الثاني (ملخص القوانين بالتفصيل — الأستاذ علي السوداني)، 27 لوحة.
- الصفحتان 2 و40 من الملف الأول مطابقتان للصفحتين 1 و39 (لوحة مكرّرة في المسح)، ولذلك لم تُفرّغا مرّتين.
- كل إضافة توضيحية خارج الأصل موسومة صراحةً بـ«ملاحظة المحرر».

## إعادة بناء صفحة الموسوعة

```bash
python3 tools/build_notes.py   # يقرأ content/muayad/*.md ويولّد notes.html
```

لا يحتاج البناء إلى أي مكتبات خارجية (Python 3 فقط). الصيغ الرياضية تُعرض بمكتبة MathJax من CDN، والخطوط من Google Fonts.

## المعاينة محلياً

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000/
```
